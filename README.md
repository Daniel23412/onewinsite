# Pixel Club · Falling Pixage

Мобильная прокладка с крупным блоком Falling Pixage, 13 обложками игр, промокодом **205bonus**, 15 вариантами языка и серверными постбэками в Telegram. Обложки взяты из ранее предоставленной прокладки, сохранены внутри проекта и показываются без обрезки.

## Как поменять ссылку

Откройте **[public/site-config.json](public/site-config.json)** на GitHub, нажмите карандаш и замените только значение `affiliateUrl`:

```json
"affiliateUrl": "https://lknw.cc/d830cc81"
```

Нажмите **Commit changes**. При подключении ветки к Vercel новая версия будет опубликована после успешного деплоя. Все карточки игр и кнопки используют эту настройку. Переход ведёт на партнёрскую страницу, где посетитель выбирает игру; прямых ссылок на отдельные игры партнёр не предоставлял.

Серверная переменная `AFFILIATE_URL`, если она заполнена, имеет приоритет над файлом. Чтобы менять адрес только через GitHub, оставьте её пустой. Значение `promoCode` меняет промокод; `showDemoFeed: false` скрывает демонстрационную ленту.

## Публикация на Vercel

Код сохранён в репозитории `Daniel23412/onewinsite`, в ветке **pixage-portal-205bonus**. Для нового проекта укажите эту ветку как Production Branch. Корневая папка проекта — корень ветки.

1. Импортируйте репозиторий в Vercel. Framework Preset — **Other**. `vercel.json` задаёт Build Command и Output Directory (`public`). Зависимости для приложения не нужны; требуется Node.js 22 или новее.
2. В настройках проекта укажите переменные ниже. Используйте значения, переданные в чате. Не добавляйте их в исходники.
3. Разверните проект. После изменения переменных выполните Redeploy, чтобы они применились.
4. Подключите адрес `/api/postback` в партнёрском кабинете по [инструкции](POSTBACKS.md).

| Переменная | Что указать |
| --- | --- |
| `BOT_TOKEN` | Токен Telegram-бота из чата |
| `POSTBACK_LOG_CHAT_ID` | ID вашего канала/чата для уведомлений |
| `POSTBACK_SECRET` | Секрет постбэков из чата |
| `AFFILIATE_URL` | Необязательно: адрес поверх настройки в файле |
| `CLICK_SIGNING_SECRET` | Необязательно: отдельный секрет подписания кликов; иначе используется `POSTBACK_SECRET` |

Бот должен иметь право отправлять сообщения в указанный канал. `.env` исключён из Git. Фронтенд не получает токен, ID канала или секрет.

**GitHub хранит код. GitHub Pages не запускает серверные функции `/api/*`.** Для этой версии используйте Vercel или Node.js-хостинг. Без серверного размещения переходы `/api/go` и постбэки не работают. Исходный сервер также можно запустить на Railway командой `npm start`.

## Языки

Автовыбор использует `navigator.languages` браузера телефона. Страна по IP не определяется. Например, если телефон из Филиппин настроен на английский, сайт откроется на английском. Ручной выбор сохраняется в браузере; в адресе также обновляется `?lang=`.

| Код | Язык |
| --- | --- |
| `fil` | Филиппинский / Filipino, также распознаётся `tl-PH` |
| `id` | Индонезийский |
| `ru` | Русский |
| `en` | Английский |
| `es-CO` | Испанский — Колумбия |
| `es-VE` | Испанский — Венесуэла |
| `es` | Испанский — остальные регионы |
| `pt-BR` | Португальский — Бразилия |
| `vi` | Вьетнамский |
| `th` | Тайский |
| `hi` | Хинди |
| `tr` | Турецкий |
| `fr` | Французский |
| `de` | Немецкий |
| `uk` | Украинский |

Порядок выбора: поддерживаемый `?lang=` → сохранённый ручной выбор → первый поддерживаемый язык браузера → английский. Пример для проверки: `https://ВАШ-ДОМЕН/?lang=es-CO`. Названия игр и промокод не переводятся.

## Лента результатов

Лента анимирована и **явно обозначена как демонстрационная на всех языках**. В ней нет утверждений о реальных игроках, зрителях онлайн или фактических выигрышах. Демо не создаёт постбэки и не отправляет сообщения в Telegram. Есть пауза; при системной настройке уменьшения анимации лента не обновляется автоматически.

## Локальный запуск и проверка

Создайте `.env` по `.env.example` и заполните серверные переменные. Затем:

```bash
npm start
```

Сайт открывается на `http://localhost:3000`. Проверка кода:

```bash
node --test tests/flows.test.mjs
node scripts/validate.mjs
```

17 тестов проверяют выбор языков, точный адрес перехода, подписи кликов, секреты, регистрацию, депозиты, повторы, параллельные запросы и повторную доставку после ошибки Telegram. В тестах Telegram заменён заглушкой: реальные сообщения не отправляются. Проверка сборки проверяет наличие всех обложек, переводы, ссылки на файлы и синтаксис. Визуальная проверка в браузере и реальные конверсии не выполнялись.

Серверные функции используют [Node.js runtime Vercel](https://vercel.com/docs/functions/runtimes/node-js), конфигурация размещения — [Vercel Project Configuration](https://vercel.com/docs/project-configuration), уведомления — [Telegram Bot API](https://core.telegram.org/bots/api#sendmessage).
